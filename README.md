# Quản Lý Lớp - Smart Class Management App

Ứng dụng **Quản Lý Lớp** tích hợp cơ sở dữ liệu Google Sheets danh sách lớp học trực tuyến thời gian thực và Cố vấn Trí tuệ Nhân tạo Gemini AI.

View your app in AI Studio: https://ai.studio/apps/e806da0e-1090-4514-baa3-fc7e41ec9116

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
